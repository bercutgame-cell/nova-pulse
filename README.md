# NOVA PULSE — MVP 0.1

Внутренняя CRM-панель NOVA DIGITAL для кампаний, импорта объявлений, дедупликации, квалификации и подготовки персональных сообщений.

## Возможности MVP
- Создание кампаний по нише и региону.
- Импорт CSV (UTF-8, UTF-8 BOM, Windows-1251).
- Дедупликация объявлений по URL.
- База лидов с поиском и фильтрами.
- Статусы обработки, заметки и история черновиков.
- Шаблоны с персонализацией: `{title}`, `{seller}`, `{city}`, `{description}`, `{price}`.
- Экспорт базы в CSV.
- Адаптивная веб-панель для смартфона.

## Локальный запуск
Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`.

## Развёртывание
Приложение использует FastAPI и SQLite. Для постоянной работы на сервере задайте `NOVA_DB_PATH` на подключённом постоянном диске. До публичного запуска обязательно добавьте авторизацию администратора, HTTPS, резервное копирование и защиту API. Текущая версия — однопользовательский MVP без авторизации; не размещайте её в открытом интернете с реальными данными.

## Формат CSV
Обязательное поле `url`. Остальные поля необязательны:

```csv
title,url,seller,city,description,price,published_at,source
Автосервис,https://example.com/ad/1,Компания,Казань,Ремонт и обслуживание,1000,2026-11-25,Импорт
```

Поддерживаются русские заголовки: `название`, `ссылка`, `продавец`, `город`, `описание`, `цена`, `дата`, `источник`.

## Источники и коммуникации
В MVP нет скрейпинга закрытых страниц, обхода CAPTCHA или автоматической массовой отправки. Данные загружаются из CSV или разрешённых источников. Сообщения создаются как черновики и отправляются вручную через доступные платформой способы.
