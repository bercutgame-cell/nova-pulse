# NOVA PULSE — MVP 0.1

Внутренняя CRM-панель NOVA DIGITAL для кампаний, импорта объявлений, дедупликации, квалификации и подготовки персональных сообщений.

## Возможности MVP
- Создание кампаний по нише и региону.\n- Раздел «Поиск Авито»: поисковые ссылки по шести нишам на всю Россию или с уточнением города.\n- Быстрое ручное добавление объявления в базу через форму с дедупликацией URL.
- Импорт CSV (UTF-8, UTF-8 BOM, Windows-1251).
- Дедупликация объявлений по URL.
- База лидов с поиском и фильтрами.
- Статусы обработки, заметки и история черновиков.
- Шаблоны с персонализацией: `{title}`, `{seller}`, `{city}`, `{description}`, `{price}`.
- Экспорт базы в CSV.
- Адаптивная веб-панель для смартфона.

## Локальный запуск
Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000`.

## Развёртывание и безопасность
Приложение использует FastAPI и SQLite. Все маршруты закрыты HTTP Basic Auth: имя пользователя `admin`, пароль задаётся через обязательную переменную окружения `NOVA_ADMIN_PASSWORD`. Если переменная не задана, приложение блокирует запросы ответом 503. Не храните пароль в GitHub.

Для постоянного хранения данных задайте `NOVA_DB_PATH` на подключённом постоянном диске. В Render Free файловая система эфемерная: SQLite-база теряется при перезапуске, простое и каждом новом деплое. Бесплатный веб-сервис также засыпает после 15 минут бездействия. Поэтому текущий бесплатный деплой подходит для проверки интерфейса, но не для хранения рабочей базы лидов. Перед реальной эксплуатацией подключите постоянное хранилище и резервное копирование.

## Формат CSV
Обязательное поле `url`. Остальные поля необязательны:

```csv
title,url,seller,city,description,price,published_at,source
Автосервис,https://example.com/ad/1,Компания,Казань,Ремонт и обслуживание,1000,2026-11-25,Импорт
```

Поддерживаются русские заголовки: `название`, `ссылка`, `продавец`, `город`, `описание`, `цена`, `дата`, `источник`.

## Поиск Авито\nРаздел формирует поисковые ссылки на публичные страницы Авито по выбранным нишам. Параметр города добавляется в поисковую фразу; пустое поле означает поиск по всей России. Пользователь вручную проверяет объявление и сохраняет его в CRM. Это не парсер и не автоматический сбор страниц.\n\n## Источники и коммуникации
В MVP нет скрейпинга закрытых страниц, обхода CAPTCHA или автоматической массовой отправки. Данные загружаются из CSV или разрешённых источников. Сообщения создаются как черновики и отправляются вручную через доступные платформой способы.
